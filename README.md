# Interactive Employee Performance & Time Series Analytics Dashboard | Power BI

## Project Overview
This project is an interactive **Power BI Dashboard** developed to analyze organizational performance, employee productivity, and time-based business trends. The dashboard transforms raw operational data into actionable insights through dynamic visualizations, KPI tracking, and interactive filtering.

The primary goal of this project is to support data-driven business decision-making by identifying:
- Best-performing marketing sources
- Employee contribution and efficiency
- Monthly and seasonal performance trends
- Cost optimization opportunities

---

## Problem Statement
Organizations often struggle to understand:
- Which marketing channels generate the best ROI?
- Which employees contribute the most to business success?
- How business performance changes over time?
- Where operational inefficiencies exist?

This dashboard addresses these challenges using interactive business intelligence reporting.

---

## Dashboard Pages

### 1. Executive Overview Dashboard
Provides a high-level summary of business performance.

#### Key Metrics:
- Total Cost
- Total Leads
- Successful Conversions
- Average Conversion Rate
- Number of Marketing Sources

#### Visuals Used:
- KPI Cards
- Clustered Column Chart
- Line Chart
- Gauge Chart
- Pie Chart

#### Key Insights:
- Compare budget across source channels
- Track conversion performance
- Monitor cost per lead
- Identify peak sales periods

---

### 2. Employee Performance Analysis
Focused on workforce productivity and contribution.

#### Visuals Used:
- Funnel Charts
- Area Chart
- Pie Chart
- KPI Cards
- Interactive Slicers

#### Key Insights:
- Top 5 employees by conversion rate
- Bottom 10 employees needing improvement
- Employee sales contribution
- Cost vs conversion efficiency

---

### 3. Time Series Analysis
Analyzes business performance over time.

#### Visuals Used:
- Line Charts
- Ribbon Chart
- Donut Chart
- Date Slicers

#### Key Insights:
- Monthly performance trends
- Seasonal sales behavior
- Cost-per-lead fluctuations
- Conversion trend forecasting
